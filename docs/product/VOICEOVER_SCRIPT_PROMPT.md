# Voiceover Script Prompt Template

Copy/paste this prompt into your preferred writing/AI tool when you want a polished narration script.

---

## Prompt (Master)

You are an expert B2B product storyteller.

I need a narration script for a [SLIDESHOW / VIDEO / DEMO WALKTHROUGH] about my platform.

### Goal
- Primary audience: [INVESTORS / PAYING CLIENTS / MIXED]
- Secondary audience: [OPTIONAL]
- Primary outcome I want: [BOOK A MEETING / SECURE PILOT / CLOSE FUNDING INTEREST]

### Platform context
- Product name: [Beds4Crew]
- Product summary: [One-platform workflow for property listings, booking operations, support flows, and subscription billing]
- Core strengths:
  1. [Security: httpOnly cookies + CSRF]
  2. [Monetization: Stripe tiered subscriptions + webhook sync]
  3. [Operations: deployment and troubleshooting playbooks]
  4. [Performance/UX: lazy loading, caching, optimized APIs, mobile-first UI consistency]

### Output requirements
1. Create a script for exactly [X] slides/scenes.
2. For each slide/scene, provide:
   - Slide title
   - On-screen bullet captions (max 3 bullets)
   - Voiceover text (40-70 words)
3. Tone: [CONFIDENT / CONCISE / FRIENDLY / ENTERPRISE]
4. Avoid technical deep dives unless needed for trust.
5. Emphasize business value, reliability, and readiness to scale.
6. End with a clear CTA.

### Optional constraints
- Total runtime target: [90 seconds / 2 minutes / 3 minutes]
- Reading level: [8th grade / professional]
- Avoid words/claims: ["guaranteed", "perfect", etc.]

Now generate:
- Version A: Investor-first
- Version B: Client-first
- Version C: Hybrid
