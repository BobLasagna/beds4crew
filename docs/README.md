# Documentation Index

Project documentation has been consolidated by area to keep the workspace root clean.

## Directories

- `docs/mobile/` - Mobile app session prompts, queue, handoff plan, and notification contract.
- `docs/deployment/` - Deployment and production rollout guides.
- `docs/email/` - Email setup, debugging, and deliverability references.
- `docs/billing/` - Stripe subscription and webhook troubleshooting docs.
- `docs/support/` - Support chat flow guide and extension examples.
- `docs/ops/` - Implementation summaries, optimization notes, and communication playbook.
- `docs/product/` - Investor/client presentation and voiceover assets.
- `docs/compliance/` - iOS/Apple compliance notes.

## Important Scripts

- `./mobile-one-click.sh` - Generates the next mobile session prompt at `docs/mobile/MOBILE_APP_AUTORUN_PROMPT.md`.
